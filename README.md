# Resume ATS Evaluator 📄

An AI-powered resume evaluation tool that analyzes your resume against job descriptions to provide ATS (Applicant Tracking System) compatibility scores and actionable recommendations.

## Features ✨

- **ATS Score Calculation**: Get a comprehensive score based on keyword matching, content similarity, and skills coverage.
- **Keyword Analysis**: Identify matching and missing keywords from job descriptions.
- **Skills Extraction**: Automatically detect technical and soft skills in your resume.
- **Actionable Recommendations**: Receive specific suggestions to improve your resume's ATS compatibility.
- **Multiple Format Support**: Upload resumes in PDF or DOCX format.
